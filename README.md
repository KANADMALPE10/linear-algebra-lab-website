# 🔢 Linear Algebra Lab

An interactive and visual Linear Algebra laboratory website featuring 8 experiments.

## 🚀 Live Demo

👉 **[Open Linear Algebra Lab](https://linear-algebra-lab-taupe.vercel.app/)**

## 🧪 Experiments

1. LU Decomposition
2. Gauss Elimination
3. Image Transformations
4. Principal Component Analysis
5. Vector Dependency & Matrix Analysis
6. Singular Value Decomposition
7. Inner Product, Norms & Orthogonality
8. Gram-Schmidt Orthogonalization
